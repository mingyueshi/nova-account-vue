# 接入方上线前检查清单

这份清单用于宿主上线验收。库的单测、浏览器 smoke 和示例 adapter 不能证明真实认证系统已经完成。

- [ ] 提供生产 `NovaAdapter`，所有方法显式失败或返回经过运行时校验的数据；删除 demo adapter、固定凭据和快捷预览。
- [ ] 使用服务端生成的挑战与验证结果；目的、邮箱、有效期和一次性消费绑定正确。第三方挑战通过 `captcha` 插槽接入，滑块百分比不作为安全证明。
- [ ] 验证码投递、验证与密码重置具有限流、有效期、一次性凭证和服务端幂等控制；响应不返回明文验证码。
- [ ] 服务端执行密码存储、权限、会话、CSRF 和安全注销；每个账户/消息/设备接口独立授权，保护当前设备会话。
- [ ] 用 `security` 插槽实现 recent-auth / passkey / TOTP 等真实二次认证及撤销流程，保持生产 `simulated` 关闭。
- [ ] 原子检查 revision；冲突后重新加载、展示差异并由用户确认。取消、超时和网络错误有明确的结果查询方式，不盲目重放写入。
- [ ] 每次 SSR 请求创建独立 adapter 和状态；会话/密钥不进入 public runtime config、props 或 hydration payload。
- [ ] 配置条款与隐私内容、宿主错误文案及 locale；检查返回的昵称、消息和活动文案是否已本地化。
- [ ] 明确时区并在服务端和客户端传入一致配置；默认 UTC 可避免 hydration 差异。自定义时间 formatter 也应确定性输出。
- [ ] 为路由参数建立 `AccountPage` 白名单。使用 `v-model:page` 同步页签；外部 page 更新是权威跳转，路由卸载/浏览器后退另设宿主离开确认。
- [ ] 核对验证码长度、资料长度和密码强度提示与后端规则。前端 `maxlength` 计 UTF-16 code units，服务端仍独立校验；强度 UI 不决定是否允许提交。
- [ ] 手工验收屏幕阅读器、真机软键盘、横屏、safe-area、焦点可见性和实际挑战 SDK；自动 axe 扫描只能覆盖部分无障碍问题。
- [ ] 在目标宿主执行浏览器 hydration、CSS 隔离、网络错误、会话失效和跨浏览器回归；确认退出/刷新后不残留账户或凭据。
- [ ] 检查 LICENSE、CHANGELOG 和打包产物；组件库与演示站点分别交付，真实发布/部署按宿主流程执行。
